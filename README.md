# 📚 GoodeeLMS Project – 학사 관리 시스템 <br> (Academic Management System)

수강 신청, 강의 관리, 성적 관리, 게시판 등 대학 학사 운영을 위한 웹 플랫폼 프로젝트입니다.<br>
설계/ERD/요구정의서 등 산출물 완비 및 GitHub 브랜치 전략을 기반으로 한 **실무형 협업 프로젝트**입니다.

🎬 [프로젝트 시연 영상 보러가기](https://youtu.be/hPClybp4v5A) | 📁 [GitHub 저장소 바로가기](https://github.com/wkdwns0501/goodeelms.git)

## 🧰 프로젝트 폴더 구조

```text
goodeelms/
├── docs/                     # 설계서, ERD, 요구정의서, PPT 등 산출물 폴더
└── src/
    └── main/
        ├── java/
        │   ├── controller/   # 요청 처리 Controller
        │   ├── dao/          # DB 데이터 접근 객체
        │   ├── dto/          # 데이터 전송 객체
        │   ├── filter/       # 권한 필터
        │   ├── listener/     # 웹 애플리케이션 리스너
        │   ├── scheduler/    # 학사 일정 자동화 스케줄러
        │   ├── service/      # 비즈니스 로직 처리
        │   └── util/         # 공통 유틸리티
        └── webapp/
            ├── resources/    # CSS, JS, Images
            └── WEB-INF/
                ├── lib/      # 라이브러리
                └── views/    # JSP 화면
```

## 🧪 테스트 및 협업 전략

| 항목 | 내용 |
|---|---|
| 테스트 플로우 | **권한별 End-to-End 시나리오 기반 테스트** (관리자 → 학생 → 교수 순) <br><br> **1) 관리자 플로우 (운영/관리 시나리오)** <br> - 관리자 로그인 → 공지사항 작성(중요 체크) → 수정/삭제 → 게시글 조회수 증가 확인 <br> - 게시글 키워드 검색 → 검색 결과/페이징 확인 <br> - 계정관리: 교수 재직상태 변경(퇴직) → 해당 교수 계정 로그인 실패 확인 <br> - 학사관리: 학생 학적상태 변경(퇴학/자퇴) → 해당 학생 계정 로그인 실패 확인 <br> - 학생등록: 신규 학생 계정 생성 → 신규 학생 최초 로그인 시 “추가 인적사항 입력 + 비밀번호 변경” 강제 흐름 확인 <br> - 장학관리: 장학생 확정 → 변경/관리에서 취소 처리 확인 <br> - 일정관리: 1년 학사일정 등록/수정 → 학생/교수 화면에 반영 여부 확인 <br><br> **2) 학생 플로우 (수강/학사 업무 시나리오)** <br> - 학생 로그인 → 마이페이지 개인정보 수정 → 비밀번호 변경(기존 비밀번호 재사용 불가) 확인 <br> - 장바구니 기간: 강의목록 조회/검색 → 장바구니 추가/삭제 → 남은 시간 표시 확인 <br> - 장바구니 비우기 → 장바구니 초기화 및 리스트 재노출 확인 <br> - 장바구니 마감 시: 정원 대비 장바구니 인원 기준으로 “자동확정/선착순 대상” 분기 표시 확인 <br> - 수강신청 기간: 남은 시간 표시 → 수강신청 버튼 전환(신청 전/후) → 수강신청 현황 반영 확인 <br> - 기간 종료 후: 내 강의에서 다음 학기 수강 강의 조회 확인 <br> - 강의평가 기간: 강의평가 완료/미완료 케이스로 성적 조회 오픈 조건 확인 <br> - 성적조회: 직전학기 성적 조회 + 전체 성적 이력(직전학기 제외) 조회 확인 <br> - 등록금: 납부이력 조회 → QR 납부 처리 흐름 확인 <br> - 학적/전공 변동이력 및 학사경고/우등이력 조회 확인 <br><br> **3) 교수 플로우 (강의/성적 시나리오)** <br> - 교수 로그인 → 강의관리에서 소속 학과 강의 조회 확인 <br> - 강의 등록 기간: 신규 강의 등록 → 등록 결과 목록 반영 확인 <br> - 성적기입 기간: 수강생 성적 입력 → 저장 처리 → 학생 성적 조회 반영 확인 <br><br> **4) 차단/정책 테스트 (보안·정합성)** <br> - 퇴직 교수 로그인 차단 확인 <br> - 자퇴/퇴학 학생 로그인 차단 확인 <br> - 관리자 등록 신규 학생: 최초 로그인 시 필수 절차(추가 인적사항/비밀번호 변경) 미완료 시 접근 제한 확인 |
| GitHub 전략 | main + develop + feature 브랜치 운영 |
